# インターフェース仕様

## tmp資格情報一覧 I/F

|No|項目名|I/O|説明|
|-:|:-|:-:|:-|
|1|No|I|資格情報の行番号|
|2|認定機関|I|資格情報の認定機関名|
|3|資格名|I|資格の名前|
|4|資格情報取得元|I|資格情報のURL|
|5|最終更新日時|O|最終更新日時（最終更新日）|
|6|タイトル|O|最終更新情報に設定されているタイトル|
|7|URL|O|最終更新情報の詳細を記載したURL|
|8|説明|O|最終更新情報の詳細説明|
|9|カテゴリ|o|認定資格のカテゴリ|
|10|試験期間|o|試験期間（試験時間）|
|11|試験の形態|o|認定試験の試験形態|
|12|費用|o|試験費用（試験料金）|
|13|受験オプション|o|オプション|
|14|はじめに|o|Introduction|
|15|試験内容|o|Exam content|
|16|試験内容の概要|o|Content outline|

列9〜16は、AWS・Google Cloud・Microsoftおよびその他認定機関について、資格ごとの「資格情報取得元」から各機関・ページの項目名・見出し・構造に基づいて取得する。値が明記されていない項目は空欄とし、取得できなかった項目で既存値を消去しない。
F列〜P列（タイトル、URL、説明、カテゴリ、試験期間、試験の形態、費用、受験オプション、はじめに、試験内容、試験内容の概要）のいずれか1つでも既存値から変更された場合は、E列（最終更新日時）に更新検知時の現在日時（JST: yyyy-MM-dd HH:mm）を設定する。

## Slack投稿

### メッセージ内容

「📢 資格情報 更新通知」の見出しに続けて、次の情報を投稿する。

|項目|内容|
|:-|:-|
|更新日時|E列に設定された現在日時（または取得元の更新日時）|
|資格名|更新情報に紐づく資格名|
|タイトル|更新情報のタイトル|
|URL|更新情報の詳細ページへのリンク|
|説明|取得元から得た説明または要約。変更項目がある場合はその概要|

### 値の扱い

|項目|取得元・形式|
|:-|:-|
|更新日時|現在日時（yyyy-MM-dd HH:mm）または取得元の形式|
|資格名|資格名|
|タイトル|タイトル|
|URL|URLをSlack上でリンクとして表示|
|説明|説明、要約の順に使用し、どちらもない場合はタイトルを使用|

日付がない場合は「未記載」、タイトルがない場合は「（タイトルなし）」、URLがない場合は「未記載」、説明に使える内容がない場合は「（詳細説明なし）」を表示する。
