# certificateInfo

## 要件

- 各サイトから資格の更新情報を収集する
- 収集は一日一回、毎平日実施する
- 各資格ごとに収集した更新情報が前回実行時より新しい情報があるか確認する
- 全認定機関の資格情報取得元から、認定機関ごとのページ構造に合わせてカテゴリ、試験期間、試験の形態、費用、受験オプション、はじめに（Introduction）、試験内容（Exam content）、試験内容の概要（Content outline）を取得する。値がページ上に明記されている項目のみ記録し、取得できない項目で既存値を消去しない
- 資格詳細ページはアクセス負荷を抑えるため5営業日に分けて確認する。詳細列だけの変更では、更新情報（最終更新日時、タイトル、URL、説明）を上書きしない
- 新しい情報がある場合
  - SpreadSheet([tmp資格情報一覧](https://docs.google.com/spreadsheets/d/1QcS6NJRvvmveI2H31xNifauDQ1A7nmMyuiGFT3xRgO8/edit?usp=sharing))の更新日時、タイトル、URL、説明を最新の情報に更新する
  - Slackの（チャンネル名未定）に更新日時、資格名、タイトル、URL、説明を整形して投稿する
  - Slackの投稿は複数の更新がある場合、それぞれ別々に実施する
